\renewcommand{\abstractname}{Summary}
\begin{abstract}
\noindent
\texttt{eitkit} is an open-source Python package for two-dimensional
difference electrical impedance tomography (EIT) on the disc. It generates
triangular meshes, simulates electrode voltages with piecewise-linear finite
elements and a point (gap) electrode model, computes the Jacobian with the
adjoint method, and reconstructs conductivity changes with Tikhonov
regularization (with an L-curve parameter choice) and total-variation
regularization (with ADMM). This note documents the model and every
algorithm as implemented, maps each step to the function that performs it,
reports the verification results (convergence to a closed-form solution,
finite-difference and reciprocity checks, golden-output tests), gives
practical guidance on choosing the mesh size and the regularization
parameters, and states the limitations. A step-by-step tutorial is provided
separately as \code{examples/00\_getting\_started.ipynb}.
\end{abstract}

\section{Introduction}
% ================================================================== %

Electrical impedance tomography recovers the conductivity $\sigma$ inside a
body from voltages measured on its boundary while currents are injected
through electrodes. The inverse problem is severely ill-posed: in the worst
case the conductivity depends on the boundary data only
logarithmically~\cite{Mandache2001}, and reconstructions must be stabilized
by regularization~\cite{Borcea2002,CheneyIsaacsonNewell1999}.
\emph{Difference} EIT avoids the need for an accurate absolute model by
imaging the change between two states, for example two breathing phases,
from the change in the measured voltages.

\texttt{eitkit} implements the standard linearized difference-imaging
pipeline for a circular domain:
\begin{enumerate}
  \item generate a mesh of the disc with electrodes at prescribed angles
        (\code{eitkit.mesh});
  \item choose the drive and measurement protocol (\code{eitkit.protocol});
  \item simulate difference voltages and compute the Jacobian
        (\code{eitkit.forward});
  \item reconstruct the conductivity change with Tikhonov or total-variation
        regularization (\code{eitkit.inverse});
  \item build phantoms and plot results (\code{eitkit.utils}).
\end{enumerate}
It is intended for teaching, for prototyping reconstruction methods, and as a
small, readable reference implementation: it depends only on NumPy, SciPy,
and Matplotlib. It is not a replacement for full-featured packages such as
EIDORS~\cite{AdlerLionheart2006}; Section~\ref{sec:limitations} lists what it
does not do.

\paragraph{Installation.} From the repository root,
\code{pip install -e ".[dev]"} installs the package with the test and
notebook dependencies; \code{uv sync --extra dev} reproduces the exact
environment recorded in \code{uv.lock}. The tutorial notebook
\code{examples/00\_getting\_started.ipynb} walks through a complete
experiment and is executed by continuous integration on every change.

% ================================================================== %
\section{The forward problem}
% ================================================================== %

\subsection{Governing equation}

Let $\Omega$ be the disc of radius $R$ (the unit disc by default) and
$\sigma\in L^\infty(\Omega)$ the conductivity, bounded below by a positive
constant. In the absence of interior sources the electric potential $u$
satisfies
\begin{equation}\label{eq:pde}
  -\nabla\cdot(\sigma\nabla u) = 0 \quad\text{in } \Omega .
\end{equation}
Current $I$ is injected at electrode $e^+$ and extracted at electrode $e^-$.
The potential is determined up to an additive constant; measured voltages are
differences of potentials, so the constant does not matter.

\subsection{Point (gap) electrode model}

\texttt{eitkit} models each electrode as a single boundary point $x_\ell$.
The boundary condition is
\begin{equation}\label{eq:gap}
  \sigma\,\frac{\partial u}{\partial n} = I\,\bigl(\delta_{x_{e^+}} -
  \delta_{x_{e^-}}\bigr) \quad\text{on } \partial\Omega ,
\end{equation}
and a voltage measurement between electrodes $a$ and $b$ is
$V = u(x_a) - u(x_b)$. This is the simplest electrode model. It ignores the
electrode width and the contact impedance, which the complete electrode
model~\cite{SomersaloCheneyIsaacson1992} includes. Near a point source the
potential has a logarithmic singularity, so the voltage at a driven electrode
is not defined by~\eqref{eq:gap}; the measurement protocol
(Section~\ref{sec:protocol}) therefore never uses a driven electrode.

For the uniform unit disc ($\sigma\equiv1$, $R=1$) the solution is known in
closed form,
\begin{equation}\label{eq:exact}
  u(x) = -\frac{I}{\pi}\Bigl(\ln|x-x_{e^+}| - \ln|x-x_{e^-}|\Bigr) + C ,
\end{equation}
because $\partial_n\ln|x-y| = \tfrac12$ on the unit circle for every
boundary point $x\neq y$, so the normal flux vanishes away from the
electrodes. Section~\ref{sec:verification} uses~\eqref{eq:exact} to verify
the solver.

\subsection{Mesh generation}

\code{make\_circle\_mesh(n\_electrodes, h0, radius, max\_iter, seed)} builds
a triangulation with target edge length $h_0$ by a node-relaxation method in
the spirit of DistMesh~\cite{PerssonStrang2004}:
\begin{enumerate}
  \item \emph{Boundary nodes.} $N_b = L\,\lceil 2\pi R/(L h_0)\rceil$ nodes
        are placed on the circle at equal angles, where $L$ is the number of
        electrodes. Boundary edges are therefore no longer than $h_0$, and
        because $N_b$ is a multiple of $L$, every electrode angle
        $2\pi\ell/L$ is a boundary node. These nodes never move.
  \item \emph{Interior seed.} A hexagonal grid with spacing $h_0$ fills the
        disc; seeds closer than $0.6\,h_0$ to a boundary node are removed and
        the rest are jittered slightly (seeded by \code{seed}) to break
        Delaunay degeneracies.
  \item \emph{Relaxation.} Interior nodes are moved by repulsive edge forces
        $\max(h_0-\ell,0)$ for up to \code{max\_iter} iterations, with a
        Delaunay retriangulation at each step; a node that leaves the disc is
        projected back onto the circle.
  \item \emph{Clean-up.} Triangles whose centroids lie outside the disc are
        removed, all triangles are oriented counterclockwise, and the boundary
        nodes are sorted by angle.
\end{enumerate}
\code{place\_electrodes(mesh, n\_electrodes, start\_angle)} returns, for each
electrode, the boundary node closest in angle to
$\theta_\ell = \code{start\_angle} + 2\pi\ell/L$; with the default
\code{start\_angle = 0} this is exactly the node placed in step~1. Electrode
$0$ lies on the positive $x$-axis and the numbering runs counterclockwise.

Table~\ref{tab:mesh} lists the resulting mesh sizes. Version~0.2.0 fixed a
defect in earlier versions, in which only the electrode nodes were placed on
the boundary: the boundary was then resolved by about 26 nodes regardless of
$h_0$, the polygonal domain did not converge to the disc, and the electrode
voltages did not converge under refinement.

\subsection{Finite element discretization}

The potential is approximated by continuous piecewise-linear (P1) functions
on the mesh, and $\sigma$ is constant on each triangle. For a triangle $T_e$
with vertices $(x_i,y_i)$, $i=1,2,3$, area $A_e$, and conductivity
$\sigma_e$, the gradient coefficients are
$b_i = y_j - y_k$ and $c_i = x_k - x_j$ for the cyclic permutations
$(i,j,k)$, and the element stiffness matrix is
\begin{equation}\label{eq:element}
  K^{(e)} = \frac{\sigma_e}{4A_e}\bigl(\mathbf b\mathbf b^\top +
  \mathbf c\mathbf c^\top\bigr) \in\mathbb R^{3\times3} .
\end{equation}
\code{assemble\_K(mesh, sigma)} sums these into the sparse global matrix $K$.
The boundary condition~\eqref{eq:gap} becomes the load vector $f$ with
$f_{e^+}=+I$, $f_{e^-}=-I$ at the electrode nodes and zeros elsewhere
(\code{build\_load\_vector}). $K$ is singular, with the constants in its
kernel; the interior node nearest the centre is grounded ($u=0$) by
symmetric row and column elimination (\code{pick\_ground\_node},
\code{apply\_dirichlet\_bc}). In \code{simulate} and \code{compute\_jacobian}
the modified matrix is factorized once with a sparse LU decomposition
(\code{scipy.sparse.linalg.splu}) and reused for every right-hand side.

\subsection{Measurement protocol}\label{sec:protocol}

\code{adjacent\_pattern(L)} returns the $L$ drive pairs $(k, k+1 \bmod L)$.
\code{measurement\_pairs(L)} returns, for each drive step $k$, the $L-3$
adjacent pairs $(m, m+1 \bmod L)$ that contain neither driven electrode, as
rows \code{[k, m, m+1]}. With $L=16$ there are $16\times13=208$ measurements.
By reciprocity, the voltage for drive pair $(a,b)$ and measurement pair
$(c,d)$ equals the voltage for drive $(c,d)$ and measurement $(a,b)$, so only
$L(L-3)/2 = 104$ measurements are independent. The Jacobian accordingly has
rank 104 (Section~\ref{sec:verification}).

% ================================================================== %
\section{Difference imaging and the Jacobian}
% ================================================================== %

\subsection{Linearization}

For a reference conductivity $\sigma_0$ (by default the constant
\code{sigma0 = 1}), \code{simulate} returns the difference voltages
\begin{equation}
  \dV = V(\sigma) - V(\sigma_0) \in\mathbb R^{P},
\end{equation}
one entry per row of \code{meas\_pairs}. The reconstruction methods use the
linear model
\begin{equation}\label{eq:linear}
  \dV \approx J\,\dsig, \qquad \dsig = \sigma-\sigma_0 ,\qquad
  J_{ie} = \frac{\partial V_i}{\partial\sigma_e}\Big|_{\sigma_0} ,
\end{equation}
with one row per measurement and one column per triangle. The relative
linearization error $\|J\dsig-\dV\|/\|\dV\|$ measures how far the data are
from this model; for the two-inclusion phantom of
Section~\ref{sec:example}, with contrasts 1.6 and 0.5 against a background of
1, it is $0.27$.

\subsection{The adjoint formula}

Let $u_k$ be the potential for drive step $k$ and $\phi_i$ the potential
generated by a unit current entering at the plus-electrode and leaving at the
minus-electrode of measurement $i$. Then~\cite{Geselowitz1971}
\begin{equation}\label{eq:sensitivity}
  J_{ie} = -\int_{T_e}\nabla u_k\cdot\nabla\phi_i\,dx ,
\end{equation}
which for P1 elements reduces to
\begin{equation}
  J_{ie} = -\frac{1}{4A_e}\Bigl[(\mathbf b\cdot\mathbf u_k^e)
  (\mathbf b\cdot\boldsymbol\phi_i^e) + (\mathbf c\cdot\mathbf u_k^e)
  (\mathbf c\cdot\boldsymbol\phi_i^e)\Bigr],
\end{equation}
where $\mathbf u_k^e$ and $\boldsymbol\phi_i^e$ are the nodal values on the
three vertices of $T_e$. The adjacent protocol uses at most $L$ distinct
measurement pairs, so \code{compute\_jacobian} needs $L$ forward and at most
$L$ adjoint solves, all with a single sparse factorization, rather than one
adjoint solve per measurement; it assembles $J$ in a few milliseconds
(Section~\ref{sec:example}).

\subsection{What the Jacobian tells you}

The singular values of $J$ decay quickly: at $h_0 = 0.08$ the 104 nonzero
singular values span about $5\times10^{5}$. The column norms of $J$ per unit
area measure the sensitivity of the data to each region; they fall by more
than an order of magnitude from the electrodes to the centre, which is why
EIT reconstructions are least resolved in the middle of the domain (see the
sensitivity map in the tutorial).

\section{Reconstruction}
% ================================================================== %

\subsection{Tikhonov regularization}

\code{tikhonov\_solve(J, dV, lambda\_, solver)} computes
\begin{equation}\label{eq:tikhonov}
  \dsig_\lambda = \arg\min_{\dsig}\ \|J\dsig-\dV\|^2 + \lambda\|\dsig\|^2
  = (J^\top J + \lambda I)^{-1}J^\top\dV .
\end{equation}
The default \code{solver="direct"} solves the $E\times E$ normal equations
with \code{numpy.linalg.solve}; \code{solver="lsqr"} applies LSQR to the
equivalent augmented least-squares system, which avoids forming
$J^\top J$.

\subsection{Choosing $\lambda$: the L-curve}

\code{choose\_lambda(J, dV, lambdas, n\_points, solver)} evaluates
$x(\lambda)=\log_{10}\|J\dsig_\lambda-\dV\|$ and
$y(\lambda)=\log_{10}\|\dsig_\lambda\|$ for candidate values (by default 50
values log-spaced between $10^{-6}s$ and $10^{2}s$ with
$s=\|J\|_F^2/P$) and returns the point of maximum signed
curvature~\cite{Hansen1992,HansenOLeary1993}
\begin{equation}\label{eq:curvature}
  \kappa = \frac{x'y''-y'x''}{(x'^2+y'^2)^{3/2}},
\end{equation}
with derivatives taken with respect to $t=\log_{10}\lambda$ by finite
differences, along increasing $\lambda$. It also returns $x$ and $y$ for
plotting.

Version~0.2.0 corrected this computation: earlier versions omitted the
denominator of~\eqref{eq:curvature}, which made the selected $\lambda$
insensitive to the noise level (the same value at 30, 45, and 60\,dB) and
placed it on the over-smoothing branch of the curve.

The L-curve is a heuristic. In the example of Section~\ref{sec:example} it
selects $\lambda = 2.3\times10^{-9}$ (relative error 0.69), against an
error of 0.58 for the best $\lambda$, which can only be found when the truth
is known. The \emph{discrepancy principle}~\cite{Morozov1966}, which chooses
$\lambda$ so that the residual matches the noise level, is unreliable in
linearized difference EIT: the residual is dominated by the linearization
error (27\% of $\|\dV\|$ in the example) rather than by the noise (0.6\% at
45\,dB), so it must be applied with an estimate of the total misfit.

\subsection{Total-variation regularization}

\code{tv\_solve(J, dV, alpha, mesh, rho, max\_iter, tol, warm\_start)}
computes
\begin{equation}\label{eq:tv}
  \dsig_\alpha = \arg\min_{\dsig}\ \tfrac12\|J\dsig-\dV\|^2 +
  \alpha\|D\dsig\|_1 ,
\end{equation}
where $D$ (\code{build\_gradient\_op}) has one row per interior edge of the
mesh and two nonzero entries, $+1$ and $-1$, for the two triangles that share
that edge. Thus $\|D\dsig\|_1$ is the sum of the absolute jumps of $\dsig$
across interior edges. Total variation~\cite{RudinOsherFatemi1992} weights
each jump by the length of its edge; $D$ does not, so on a quasi-uniform mesh
$\|D\dsig\|_1$ approximates $\mathrm{TV}(\dsig)/\bar h$ for a typical edge
length $\bar h$, and the appropriate $\alpha$ changes with $h_0$.

Problem~\eqref{eq:tv} is solved by ADMM~\cite{Boyd2011} with the splitting
$z = D\dsig$ (Algorithm~\ref{alg:admm}). The $\dsig$-update matrix
$H = J^\top J+\rho D^\top D$ is symmetric positive definite and is factorized
once, so each iteration costs one pair of triangular solves and a few sparse
products. With \code{rho="auto"} the penalty is
$\rho = \operatorname{tr}(J^\top J)/\operatorname{tr}(D^\top D)$, which
balances the two terms of $H$.

\begin{algorithm}[ht]
\caption{ADMM for TV-regularized difference EIT (\code{tv\_solve})}
\label{alg:admm}
\begin{algorithmic}[1]
\Require $J$, $\dV$, $\alpha>0$, $\rho>0$, tolerance $\varepsilon$, starting
point $\dsig^0$ (zero, or \code{warm\_start})
\State factorize $H = J^\top J + \rho D^\top D$; set $z^0=u^0=0$,
$\kappa = \alpha/\rho$
\For{$k = 0,1,\dots,\code{max\_iter}-1$}
  \State $\dsig^{k+1} = H^{-1}\bigl(J^\top\dV + \rho D^\top(z^k-u^k)\bigr)$
  \State $z^{k+1} = \mathcal S_\kappa\bigl(D\dsig^{k+1}+u^k\bigr)$
  \Comment{$\mathcal S_\kappa(v) = \operatorname{sign}(v)\max(|v|-\kappa,0)$}
  \State $u^{k+1} = u^k + D\dsig^{k+1} - z^{k+1}$
  \If{$\|D\dsig^{k+1}-z^{k+1}\| \le \varepsilon\max\bigl(\|D\dsig^{k+1}\|,
  \|z^{k+1}\|, 1\bigr)$} \textbf{stop} \EndIf
\EndFor
\State \Return $\dsig^{k+1}$
\end{algorithmic}
\end{algorithm}

\section{Verification}\label{sec:verification}

\subsection{Convergence to the exact solution}

\code{scripts/verify\_convergence.py} compares the FEM electrode voltages with
the closed form~\eqref{eq:exact} on the uniform unit disc, for every drive
step of the adjacent protocol and all 13 measurements per step, on meshes
with $h_0$ from 0.2 to 0.025. Table~\ref{tab:convergence} and
Figure~\ref{fig:convergence} show the mean relative error. It decreases at
every level, at a rate close to two; the meshes are not nested, so the
observed rate varies between levels. Before the mesh fix of
version~0.2.0 the same study gave errors of 0.25, 0.10, and 0.027 at
$h_0=0.1$, $0.05$, and $0.025$, without monotone decrease.

\subsection{Jacobian and reciprocity}

\begin{itemize}
  \item \emph{Finite differences.} \code{scripts/verify\_jacobian.py}
        compares 20 entries of the adjoint Jacobian with central finite
        differences of \code{simulate}; the largest relative difference is
        $2.4\times10^{-7}$.
  \item \emph{Reciprocity.} Swapping drive and measurement pairs changes the
        computed voltage by at most $1.3\times10^{-15}$ (relative) on an
        inhomogeneous conductivity, as the symmetry of $K$ requires.
  \item \emph{Rank.} $J$ has numerical rank $104 = L(L-3)/2$ at $h_0 = 0.1$,
        $0.08$, and $0.05$, as reciprocity predicts.
\end{itemize}

\subsection{Automated tests}

The test suite (177 tests, \code{pytest}) checks mesh validity and quality,
the protocol, the forward solver and Jacobian, both reconstruction methods,
the L-curve corner (including its dependence on the noise level), the
phantoms and plotting helpers, boundary resolution and forward convergence
against~\eqref{eq:exact}, and a golden-output test that reruns the demo
notebook's pipeline and compares mesh counts, voltages, and reconstruction
errors with stored values (\code{tests/golden/demo\_notebook.json}).
Continuous integration runs the suite on Python 3.10 to 3.13, runs every
script from outside the repository, and executes both notebooks.

\section{Choosing the parameters}\label{sec:parameters}
% ================================================================== %

\paragraph{Mesh size $h_0$.} The forward error is about 0.9\% at $h_0=0.1$
and 0.15\% at $h_0=0.05$ (Table~\ref{tab:convergence}), which is well below
the noise and linearization errors of typical experiments. The number of
triangles $E$ grows like $h_0^{-2}$; the Jacobian costs $O(PE)$ memory and the
direct Tikhonov solve up to $O(E^3)$ operations, so $h_0$ between 0.05 and
0.1 is a good default. For honest tests, simulate data on a finer mesh than
the one used for reconstruction.

\paragraph{Tikhonov parameter $\lambda$.} The scale of $\lambda$ follows the
scale of $J^\top J$, which depends on the current, the domain, and the mesh.
Start from the L-curve corner, plot the reconstruction for $\lambda$ ten
times smaller and larger, and prefer the largest $\lambda$ that keeps the
features you expect. For the example ($I=1$, unit disc, $h_0=0.08$), good
values lie between $10^{-9}$ and $10^{-7}$.

\paragraph{TV parameter $\alpha$.} In the example, $\alpha$ between
$5\times10^{-8}$ and $10^{-7}$ gives the smallest errors (0.426 and 0.418);
$\alpha=10^{-8}$ and $2\times10^{-7}$ give 0.458 and 0.452. Because $D$ is
not weighted by edge length, retune $\alpha$ when you change $h_0$. ADMM
usually converges within a few hundred iterations; increase
\code{max\_iter} or decrease \code{tol} if the result changes between runs
with more iterations, and use \code{warm\_start} when sweeping $\alpha$.

\paragraph{Noise and contrast.} \code{add\_noise(dV, snr\_db, rng)} adds
white Gaussian noise at a prescribed SNR over the whole vector. Real systems
also have systematic errors (electrode positions, contact impedance) that the
model does not include; treat the SNR as an upper bound on data quality.
Large contrasts increase the linearization error and make the reconstructed
contrast too small.

\section{Limitations}\label{sec:limitations}
% ================================================================== %

\begin{itemize}
  \item \emph{Geometry.} Two-dimensional discs only; real bodies are three
        dimensional, and currents spread out of the electrode plane.
  \item \emph{Electrodes.} Point electrodes without contact impedance; the
        complete electrode model~\cite{SomersaloCheneyIsaacson1992} is not
        implemented, and voltages at driven electrodes cannot be used.
  \item \emph{Protocol.} Adjacent drive and adjacent measurement only.
  \item \emph{Imaging.} Linearized difference imaging with a single step;
        there is no iterative (Gauss--Newton) reconstruction and no absolute
        imaging.
  \item \emph{Scale.} $J$ and $J^\top J$ are dense, so memory grows like
        $E^2$; meshes with more than a few thousand triangles become slow.
  \item \emph{TV operator.} Edge jumps are not weighted by edge length, so
        $\alpha$ depends on the mesh size.
  \item \emph{Uncertainty.} No uncertainty quantification.
\end{itemize}
